## 🌟 Project Overview

**Hit Me Up** is a simple and lightweight visitor counter service that tracks visitor counts in real-time for specific
URLs and displays them as SVG badges.

Add just one line of code to easily display visitor counts anywhere - GitHub README, Notion, blogs, and more.

- Real-time visitor count tracking per URL

- Lightweight with no impact on page performance

- Free & Open Source Project

## ⚙️ How to Use

1. Visit the [Hit Me Up Service Page](https://hit-me-up-336ec.web.app/)

2. Configure the URL you want to track and badge options (text, colors, etc.)

3. Click the `GENERATE BADGE` button

    <img width="1634" height="878" alt="Generating Badge" src="https://github.com/user-attachments/assets/9b7c2bc3-439c-4f77-b74c-d4a428297ade" />

4. Insert the generated code into your GitHub README, Notion, website, or anywhere you want

    <img width="1646" height="1812" alt="Code View" src="https://github.com/user-attachments/assets/e389b3a0-40b8-45cd-8426-2785c80bc1f3" />

The visitor count will automatically increment with each new visit.

<br/>

## 🎯 Key Highlights

- Visitor counters are managed separately for each URL, with data consistency guaranteed through Firestore transactions

- Preview mode is provided to prevent visitor count increments during badge generation

- Static files and backend API are deployed separately through Firebase Hosting and Cloud Run integration

- Stable service delivery through proper region configuration and domain mapping using Cloud Run
