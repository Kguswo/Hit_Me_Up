# Hit Me Up 

원하는 URL의 방문자 카운터를 쉽고 빠르게 만들어보세요!

뱃지를 생성하고 단 한 줄 코드를 추가하면 자동으로 방문자 수를 추적할 수 있어요.

## 🌟 프로젝트 소개

**Hit Me Up**은 방문자 수를 특정 URL별로 실시간 집계하여 SVG 뱃지로 보여주는 간단하고 가벼운 방문자 카운터 서비스입니다.

한 줄 코드만 추가하면 GitHub README, Notion, 블로그 등 어디에나 쉽게 방문자 수를 표시할 수 있습니다.

## 🚀 주요 기능

- 단 한 줄 코드 삽입으로 쉽고 빠르게 

- URL별 실시간 방문자 수 자동 집계  

- SVG 형식의 커스텀 가능한 방문자 카운터 뱃지 생성  

- 페이지 성능에 영향 없이 가볍게  

- 무료 & 오픈소스 프로젝트

## ⚙️ 사용 방법

1. [Hit Me Up 서비스 페이지](https://hit-me-up-336ec.web.app/) 접속

2. 방문자 수를 추적려는 URL과 배지 옵션(텍스트, 색상 등)을 설정  

3. `GENERATE BADGE` 버튼 클릭

    <img width="1634" height="878" alt="Generating Badge" src="https://github.com/user-attachments/assets/9b7c2bc3-439c-4f77-b74c-d4a428297ade" />

4. 생성된 코드를 자신의 GitHub README, Notion, 웹 사이트 등 원하는 곳에 삽입  

    <img width="1646" height="1812" alt="Code View" src="https://github.com/user-attachments/assets/e389b3a0-40b8-45cd-8426-2785c80bc1f3" />

새로운 방문이 생길 때마다 방문자 수가 자동으로 증가합니다.

<br/>

## 🎯 주요 특징

- 방문자 수 카운터는 URL마다 분리하여 관리하며, Firestore 트랜잭션으로 데이터의 일관성을 보장  

- 미리보기 모드(preview)를 제공해 배지 생성 시 방문자 수 증가가 불가능하도록 설계되었습니다. 

- Firebase Hosting과 Cloud Run 연동을 통해 정적 파일과 백엔드 API를 분리 배포하였습니다. 

- Cloud Run을 사용한 적절한 리전 설정 및 도메인 매핑을 통한 안정적인 서비스 제공합니다.
